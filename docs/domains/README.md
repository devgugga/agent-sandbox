# Domain Packs

Domain knowledge in this repository is stored as portable, tool-agnostic Markdown packs consumed by all AI tools (Google Antigravity, Claude Code, OpenAI Codex, Gemini CLI).

## Available Domain Packs

- [`git/`](./git/commit-conventions.md): Git commit conventions, Gitmoji standards, branch policy, and structured commit bodies.
- [`sandbox/`](./sandbox/README.md): Architecture, networking, firewall, credentials, troubleshooting, and Orca integration for `agent-sandbox`.
- [`review/`](./review/README.md): Rules for the read-only review roles: test shape, claim verification, and known-regression checking.
- [`server/`](./server/README.md): The `asb-server` FastAPI daemon — package layout, the worker-thread rule, the error model, authentication, and testing conventions.
- [`web/`](./web/README.md): The React front end — component structure, server state management, the command-palette principle, and testing conventions.
