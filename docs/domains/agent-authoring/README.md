# Agent Authoring Domain Pack

This domain establishes conventions, architecture standards, directory layouts, model routing guidelines, and validation checklists for creating and maintaining agents and skills across AI platforms (Google Antigravity, Claude Code, OpenAI Codex).

## Documents

* [`conventions.md`](./conventions.md): Principles of Domain Packs as SSoT, thin wrappers, and boundaries.
* [`platform-layouts.md`](./platform-layouts.md): Platform discovery contracts and folder structures.
* [`model-selection.md`](./model-selection.md): Workload classification and cost-effective model routing.
* [`validation.md`](./validation.md): Verification checklists and human review gates.
